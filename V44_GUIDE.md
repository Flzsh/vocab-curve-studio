# Vocab Curve Studio V44

## Run

1. Extract the ZIP.
2. In the extracted folder, run `python3 -m http.server 4173`.
3. Open `http://localhost:4173/`.

## What changed

- Short-term mastery remains day-scoped and requires delayed independent recall before a word becomes secure.
- A **Continue** control can open the next set when only a small repeated weak group remains; those weak words stay in review.
- The deterministic scheduler and recall calibration use the same canonical review evidence.
- Import is integrated into **Books**.
- Stats reads current saved scheduler, short-term, long-term, and calibration data.
- Low Power mode pauses nonessential continuous visual work while keeping study and storage functional.
- Pro Tutor sends richer learner evidence and can use individual or multi-word strategies, including bridges, contrasts, applications, linked sentences, and mini-stories.
- Default Book 2 contains 558 entries from the supplied vocabulary PDF, organized in 100-word chapters and 20-word sets.

## Data safety

Progress is local to the browser profile and origin. Export a full backup before changing browsers, devices, folders, or local-server ports.

## OpenRouter

Enter or connect an OpenRouter key in Settings, select a model, and use **Test tutor**. The release audit mocked the provider path; it did not spend a live API request.

## Curated Book 2 bridges

The bundled 耕读 book now provides a direct Chinese memory bridge and a natural English practice sentence for every one of its 558 cards. Bridges favor transparent word parts, vivid scenes, and useful meaning boundaries instead of dictionary fragments.
