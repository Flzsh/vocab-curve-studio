# Vocab Curve Studio V47

Local-first adaptive vocabulary study with organized books, mixed review/new scheduling, complete selectable themes, offline support, and optional OpenRouter Pro Tutor.

## Run locally

1. Extract this ZIP.
2. Open a terminal in the extracted folder.
3. Run `python3 -m http.server 4173`.
4. Open `http://localhost:4173/`.

## V47 highlights

- Choose **Follow system**, **Light**, or **Dark** in Settings. Dark mode covers Study, Books, Planner, Stats, Settings, disclosures, dialogs, Pro Review, and phone navigation.
- Reveal keeps the flashcard at its full width. Meaning, bridge, context, and Wrong/Correct/Know remain in one answer surface.
- **Ultra Battery** stops CSS animations, transitions, liquid motion, memory-world movement, ripples, and other continuous visual effects while preserving Study, ratings, scheduling, saving, Books, Stats, and Pro Tutor.
- Phone navigation uses three stable destinations: **Study**, **Books**, and **More**.
- Normal Study retains the persistent **7 reviews / 3 new words** cadence whenever both pools are available. Review only remains available.
- SAT L1–L3, 耕读 Book 2, Word Smart Book 3, Quick Quiz diagnostics, Books/Import, Stats, recall calibration, and protected saves remain supported.

Progress is stored in the current browser profile and origin. Export a full backup before changing devices, browser profiles, folders, ports, or origins.
